ROOTWAKE - Windows version

Double-click ROOTWAKE.exe to start the game. Keep ROOTWAKE.exe and ROOTWAKE.pck in the same folder.
Recommended display: 1920 x 1080 or higher. Audio on.

If Windows asks for confirmation before running a downloaded file, verify that this package came from the project owner.

Made with Godot Engine 4.7.2 (https://godotengine.org/).
